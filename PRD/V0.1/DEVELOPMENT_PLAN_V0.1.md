## 一、 研发里程碑与版本节奏 (Milestones)

按照敏捷迭代方式，分为 4 个主要里程碑（4 个 Sprint，每周 1 个 Sprint）：

```
[M1: 系统探针与内核 POC] (W1)
       ↓
[M2: AI 编排与意图流转闭环] (W2)
       ↓
[M3: 主看板与原生提醒体验] (W3)
       ↓
[M4: 异常加固与交付发布] (W4)
```

| 里程碑 | 核心目标 | 交付物与验收标准 |
| :--- | :--- | :--- |
| **M1: 内核探针与基础框架 (Week 1)** | 攻克系统级底层技术壁垒，打通骨架流程 | 1. 全局快捷键注册与冲突检测；<br/>2. 剪贴板无感安全捕获与还原（耗时 < 100ms）；<br/>3. 活动窗口与前台进程识别；<br/>4. 无焦点悬浮微窗原型。 |
| **M2: AI 意图流转与核心闭环 (Week 2)** | 跑通“划选 -> AI 智能路由 -> 自动/轻交互归档” | 1. SQLite 数据库初始化与 DAO 层；<br/>2. LLM 结构化 Prompt 与 JSON Schema 严格校验；<br/>3. 置信度三大分支流转（自动归档、单键确认、新建）；<br/>4. 右下角 HUD 微窗交互完整闭环。 |
| **M3: 主看板与定时提醒打磨 (Week 3)** | 事项全景复盘与待办主动触达 | 1. 事项卡片看板、多维排序与过滤；<br/>2. 事项详情抽屉与倒序时间轴；<br/>3. 待办全局视图与聚焦模式；<br/>4. 本地 Windows 原生定时 Toast 提醒调度。 |
| **M4: 体验加固与发布测试 (Week 4)** | 稳定性加固、异常防御、打包构建 | 1. 离线缓存与 API 失败重试容错；<br/>2. 模型设置中心（支持自定义 API Key）；<br/>3. 内存泄漏与常驻 CPU 优化；<br/>4. Windows 安装包打包（.msi / .exe）与自动化验证。 |

## 三、 关键风险评估与应对预案 (Risk Management)

| 风险项 | 风险等级 | 潜在影响 | 应对与缓解预案 |
| :--- | :--- | :--- | :--- |
| **1. 剪贴板竞争与死锁** | **高** | 某些软件打开了剪贴板或用户连续快速触发，导致 `OpenClipboard` 失败或原剪贴板内容损坏 | ① 引入重试退避机制（重试 3 次，间隔 20ms）；<br/>② 增加互斥锁（Mutex），同一时刻只允许一个抓取任务；<br/>③ 若连续失败则降级为只读不还原，并向用户发送告警。 |
| **2. 某些特定应用选中文本拦截** | **中** | 部分极特殊安全应用（如网银控件、虚拟机）拦截了模拟的 `Ctrl + C` 按键 | ① 先调用 UIAutomation 尝试无按键读取选中文本；<br/>② 若未命中则执行 `SendInput(Ctrl+C)`；<br/>③ 若两者均为空，弹出提示“请手动复制后按快捷键导入”。 |
| **3. 大模型解析延迟与弱网** | **中** | 网络抖动导致调用超时，用户等待超过 3 秒，体验受损 | ① HUD 微窗在捕获 50ms 内立刻弹出“AI 正在思考”动效，给予即时操作反馈；<br/>② 设定 5s 超时阈值，超时后自动转入本地“未分类收集箱”，不阻塞用户后续操作。 |
| **4. 全局快捷键冲突被占用** | **低** | 用户系统中已存在其他软件注册了相同的快捷键（如微信自带截图占用） | ① 启动时注册失败即刻在托盘弹出气泡提醒；<br/>② 设置面板提供一键重设和按键录制组件，支持一键切换备用推荐热键（如 `Alt + Z`）。 |
| **5. 大模型输出非预期格式** | **中** | 某些模型未严格遵循 JSON 格式，导致前端解析崩溃 | ① 强制开启各厂商的 `response_format: { type: "json_object" }` 参数；<br/>② 在客户端引入强校验与正则提取器（自动剔除 markdown 的 ````json 标记）。 |

## 四、 质量验收标准 (Definition of Done - DoD)

每一个功能模块只有同时满足以下标准方可视为交付完成：
1. **交互延迟要求**：
   - 快捷键按下到 HUD 悬浮微窗弹出的视觉反馈时间 $\le 100\text{ms}$；
   - 剪贴板还原耗时 $\le 150\text{ms}$，用户剪贴板数据 100% 完整复原；
2. **常驻资源要求**：
   - 桌面后台静默待机时，CPU 占用率 $< 0.1\%$，内存占用 $< 80\text{MB}$；
3. **数据一致性与安全性**：
   - 本地 SQLite 读写支持 WAL 模式，确保应用意外退出时不丢数据；
   - API Key 必须使用本地系统级安全凭证库存储，禁止明文写在日志中；
4. **测试覆盖**：
   - 核心领域模型（事项、待办、时间解析算法）单元测试覆盖率 $\ge 80\%$；
   - 覆盖微信、企业微信、飞书、Chrome、Edge、记事本 6 款核心桌面宿主软件的选词划选兼容性回归测试。
